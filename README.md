# 📚 통합 학습기

수학 · 과학 · 역사 · 영어(문법·단어·독해·듣기) · 회화를 **수학 앱과 같은 방식**(학년 → 단원 → 수업: 도입 → 개념 → 확인 문제 → 정리)으로 공부하는 앱(PWA)입니다.
학습 기록은 **사용자별로 하나**이며, GitHub 저장소와 동기화해 다른 기기에서도 같은 기록을 봅니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행

```bash
python -m http.server 8770 --directory "E:\프로그램 제작\학습기"
```

http://localhost:8770 을 엽니다. 휴대폰·태블릿에서 쓰려면 GitHub Pages 같은 **https** 주소에 올려야 합니다(오프라인 저장·설치는 https에서만 됨).

## 과목 구성

| 과목 | 학년(단계) | 단원 | 수업 내용 |
|---|---|---|---|
| ➗ 수학 | 초5~고3 (8) | 74 | 원래 수학 앱 그대로: 개념·움직이는 그래프·문제 은행(난이도 1~5) |
| 🔬 과학 | 초등, 중1~고3 (7) | 62 | 단원별 개념 설명 3~4개 + 문제 15개(난이도별 3개) 새로 작성, 기존 그림 문제·계산 문제 포함 |
| 🏯 역사 | 초등·중등·고등·공무원 (4) | 36 | 시대 소개·사진 + 해설에서 뽑은 핵심 정리, 문제 3,294개(OX·순서 문제는 4지선다로 변환, 사료·그림 포함) |
| 📘 영어 | 중1~고3 (6) | 121 | 학년 안에서 **✏️ 문법 · 🖼️ 단어 · 📖 독해 · 🎧 듣기** 파트로 나눠 공부(내신·모의고사·수능). 문법·독해: 개념(표·🔊 예문) + 문제 15개, 지문은 모두 새로 쓴 글. 단어: 주제 6개 × 24단어 그림 카드('뜻 가리기'), 문제 자동 생성. 듣기: 기기 음성이 남·여 목소리로 대화를 읽고, 대본은 답한 뒤 해설에 |
| 🗣️ 회화 | 초등·중등·고등·일반 (4) | 1,074 | 상황·미션 → 핵심 표현(🔊 듣기) → 문제(뜻·표현·빈칸·어순·듣기) → **AI와 말하기** → 정리. 영어/일본어 |

- 수업 위쪽의 도입·개념·문제·정리(와 단계 칸)를 누르면 그 단계로 바로 간다. 정리는 문제를 다 푼 뒤에 열린다.
- 수업은 한 화면에 한 단계씩, 문제는 답을 골라야 다음으로 넘어갑니다. 난이도는 '섞어서' 또는 1~5단계를 고르고, 지난 결과로 추천 난이도를 정합니다.
- 회화의 AI와 말하기는 인터넷 + OpenAI API 키(설정)가 있으면 진짜 AI, 없으면 연습용 대화로 진행합니다. 건너뛰어도 됩니다.
- 예전 과목 앱의 자체 기록·카톡 보내기·게임 화면은 없앴습니다. 기록·보고서는 '기록' 탭 하나에 모였습니다.

## 화면

- **홈**: 오늘의 학습(연속일·포인트·별), 오늘의 계획(이어서 하기 → 과목마다 내 단계의 다음 단원 → 오답 복습), 과목 카드, 맞춤 추천, 오늘 공부 카톡 보내기
- **학습**: 과목 → 학년(검색 가능) → 단원 목록 → 수업
- **기록**: 📅 날짜별(달력·그날 수업·카톡 보내기·최근 7일 보고서) / 🎯 실력·추천(과목·단계별 정답률, 선행 학습 추천) / 📝 오답 노트 / 📦 보관함(초기화·되돌리기·삭제)
- **설정**: 프로필(이름·학년·보고서 받는 사람), 과목별 내 단계, 회화 언어, GitHub 동기화, OpenAI 키, 카카오 키, 앱 설치·오프라인 상태, 로그아웃

선행 학습 추천: 최근 30일 내 단계에서 20문제 이상·85% 이상이면 다음 단계, 60% 미만이면 복습(50% 미만은 한 단계 아래). 어려운 문제(4·5)를 80% 이상 맞힌 단원은 이어지는 단원(수학은 윗학년 연계 단원)을 추천합니다.

## 사용자 · 기록 동기화 (GitHub)

1. GitHub에서 **비공개(Private)** 저장소를 하나 만듭니다. 예: `jeedan81/learner-data` (README만 있어도 됨)
2. GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token
   - Repository access: *Only select repositories* → 위 저장소 하나
   - Permissions → Repository permissions → **Contents: Read and write**
3. 각 기기의 학습기 로그인 화면(또는 설정)에서 저장소 이름과 토큰을 넣고 "저장하고 연결 확인"을 누릅니다.
4. 아이디·비밀번호로 로그인합니다. 처음 쓰는 아이디면 이름·학년을 정해 새로 만듭니다. 다른 기기에서도 같은 아이디·비밀번호로 로그인하면 같은 기록이 보입니다.

- 기록 파일: 저장소의 `users/<아이디>.json`. 공부할 때마다 몇 초 뒤 자동으로 올리고, 앱을 열거나 인터넷이 다시 연결되면 받아서 합칩니다. 오프라인에서 공부한 기록도 연결되면 올라갑니다.
- 여러 기기에서 동시에 공부해도 수업 기록 단위로 합쳐지므로 서로 지워지지 않습니다.
- 주의: 토큰이 들어간 기기에서는 같은 저장소의 모든 사용자 파일에 접근할 수 있습니다. 비밀번호는 가족끼리 사용자를 구분하는 용도입니다. 토큰은 그 저장소 하나에만 권한을 주세요.
- 동기화를 켜지 않으면 기록은 그 기기에만 저장됩니다.

## 인터넷 없이 쓰기

처음 한 번 열면 앱 파일 전체(약 8MB, 148개)를 기기에 저장합니다. 그 뒤에는 네 과목 수업·문제, 기록·추천·보관함이 인터넷 없이 됩니다.
인터넷이 필요한 것: 회화 AI 대화, 기록 동기화(연결되면 자동), 카카오톡 보내기. 화면 오른쪽 위에 연결·동기화 상태가 보입니다.

**파일을 고친 뒤에는 꼭** `node tools/build-sw.js` 를 실행하세요(오프라인 파일 목록·버전 갱신).

## 구조

```
index.html                 화면 뼈대
css/platform.css           수학 앱 스타일(그대로)
css/extra.css              로그인·기록·회화 대화·넓은 화면 등 추가 스타일
js/core.js                 과목 등록·불러오기, 사용자 기록(이벤트), 진도 계산, 초기화·보관함, GitHub 동기화
js/subjects.js             네 과목 데이터를 학년·단원·개념·문제 은행으로 바꾸는 어댑터
js/app.js                  화면(홈·학습·수업·기록·설정·로그인), 추천, 보고서·카카오톡
js/figs.js                 문제 그림 자동 생성(수학: 문제 글의 도형·치수·식·자료를 읽어 SVG로, 회화: 상황 카드)
js/music.js                집중 음악(앱바 🎵): Web Audio로 소리를 만들어 음원 파일 없이 오프라인 재생
data/math/                 수학 단원·문제 은행 (원래 수학 앱 데이터)
data/science/              questions.js·images.js(원래 과학 앱) + content-*.js(새 개념·문제) + figs.js(단원·낱말별 문제 그림), GUIDE.md·check.js(작성 기준·검사)
data/history/              시대별 문제·그림·사진(원래 역사 앱). 사진이 없는 문제는 문제·해설의 유물·인물 이름으로 사진을 찾아 붙인다(js/subjects.js HIS_KW)
data/english/              영어 단원 content-*.js(문법·독해·듣기), 단어 단원 vocab-*.js, 작성 기준 GUIDE.md, 검사 check.js. 새 파일은 js/subjects.js 목록의 맨 뒤에 붙인다(단원 번호 유지)
data/talk/                 상황 데이터·AI 모듈 api.js(원래 회화 앱, 오프라인 안내 추가)
sw.js, precache.js         오프라인(precache.js는 tools/build-sw.js가 생성)
```

과학 콘텐츠 검사: `node data/science/check.js data/science/content-*.js`

영어 콘텐츠 검사: `node data/english/check.js data/english/content-*.js data/english/vocab-*.js`
