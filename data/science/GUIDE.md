# 과학 단원 콘텐츠 작성 기준

통합 학습기의 과학 과목을 수학 앱과 같은 수업 형식(도입 → 개념 → 확인 문제 → 정리)으로 바꾸기 위해,
단원마다 **개념 설명(sections)** 과 **문제 은행(bank)** 을 새로 쓴다. 대상은 한국 초·중·고 학생(2022 개정 교육과정 기준, 학년 수준에 맞는 용어).

## 출력 형식 (JavaScript, 파일 하나에 맡은 단원 전부)

```js
SCI.add('m1', '여러 가지 힘', {
  sub: '한 줄 설명(30자 안팎)',
  kw: ['검색용 핵심어', '...'],               // 4~8개
  sections: [                                 // 3~4개. 한 화면에 하나씩 보여 준다
    { h: '소제목',
      p: '본문. HTML 허용: <span class="hl">강조</span>, <b>굵게</b>, <br>. 2~5문장',
      table: { head: ['구분', '...'], rows: [['...', '...']], cap: '표 설명(선택)' },   // 선택
      formula: ['F = m × a', '...'],          // 선택. 공식·관계식이 있는 단원만
      p2: '표·공식 뒤에 이어지는 본문(선택)',
      tip: '기억 요령(선택)', warn: '자주 하는 실수(선택)' },
  ],
  bank: [                                     // 정확히 15문제: lv1 3개, lv2 3개, lv3 3개, lv4 3개, lv5 3개
    { lv: 1, q: '문제', o: ['보기1', '보기2', '보기3', '보기4'], a: 0, why: '해설 1~2문장' },
  ],
});
```

- `a`는 정답 보기의 번호(0~3). **정답 위치를 0~3에 고르게 섞을 것**(전부 0이면 안 됨).
- 난이도: 1 기초(용어·대표 사실) · 2 기본(개념 확인) · 3 표준(개념 적용) · 4 응용(비교·원인과 결과·자료 해석) · 5 심화(계산·여러 개념 종합·실험 설계).
  계산이 가능한 단원(힘, 속력, 밀도, 전기 회로, 화학 반응식 등)은 lv4~5에 숫자 계산 문제를 넣는다. 계산은 두 번 검산.
- 보기 4개는 모두 그럴듯하게, 중복·"모두 정답" 금지. 문자열 안 따옴표는 작은따옴표 대신 「」나 ‘’를 쓰거나 이스케이프.
- 사실 정확성이 가장 중요하다. 확실하지 않은 내용은 쓰지 말 것. 초등은 쉬운 말(해요체), 중등 이상은 교과서 문체.
- 다른 전역 변수나 함수를 만들지 말고 `SCI.add(...)` 호출만 쓴다.
