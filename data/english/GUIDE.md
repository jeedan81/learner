# 영어(입시) 단원 콘텐츠 작성 기준

통합 학습기의 **영어** 과목(회화와 별개)을 다른 과목과 같은 수업 형식(도입 → 개념 → 확인 문제 → 정리)으로 만든다.
대상은 한국 중1~고3 학생. 목표는 **내신·모의고사·수능** 대비: 문법(어법), 어휘, 독해 유형.

## 출력 형식 (JavaScript, 파일 하나에 맡은 단원 전부)

```js
ENG.add('h1', '어법 판단: 수일치와 동사', {
  sub: '한 줄 설명(30자 안팎)',
  kw: ['핵심어', '...'],                        // 4~8개 (한글·영어 섞어도 됨)
  sections: [                                    // 3~4개. 한 화면에 하나씩 보여 준다
    { h: '소제목',
      p: '설명 본문(한국어). HTML 허용: <span class="hl">강조</span>, <b>굵게</b>, <i>기울임</i>, <br>. 2~5문장',
      table: { head: ['구분', '형태', '예문'], rows: [['...', '...', '...']], cap: '표 설명(선택)' },
      ex: [['영어 예문', '우리말 뜻'], ...],     // 선택. 예문 2~4개 (화면에 🔊 듣기 버튼이 붙는다)
      p2: '표·예문 뒤 본문(선택)',
      tip: '기억 요령(선택)', warn: '자주 하는 실수(선택)' },
  ],
  bank: [                                        // 정확히 15문제: lv1 3개, lv2 3개, lv3 3개, lv4 3개, lv5 3개
    { lv: 1, q: '문제', o: ['보기1', '보기2', '보기3', '보기4'], a: 0, why: '해설(한국어) 1~3문장' },
  ],
});
```

- **표(table)는 단원마다 최소 1개**(문법 형태 정리, 유형별 풀이 순서, 연결어 정리 등). 예문(ex)은 개념 칸마다 넣는 것을 권장.
- 독해 문제의 지문은 `q` 안에 `<div class="passage">…영어 지문…</div>` 로 넣는다. 밑줄은 `<u>…</u>`, 빈칸은 `<span class="blank"></span>`,
  번호 표시는 ①②③④⑤ 문자. 어법 문제에서 고를 부분은 `<u>①&nbsp;word</u>`처럼 표시.
- 보기는 4개(앱이 4지선다). 수능은 5지선다지만 이 앱에서는 4개로 만든다.
- `a`는 정답 보기 번호(0~3). **정답 위치를 0~3에 고르게 섞을 것**.
- 난이도: 1 기초(형태·뜻) · 2 기본(규칙 적용) · 3 표준(문장 속 판단) · 4 응용(짧은 지문·두 개념 결합) · 5 심화(모의고사·수능형 지문 문제).
  학년이 높을수록 lv4~5는 실제 모의고사 수준의 지문(중3 60~100단어, 고1~2 100~150단어, 고3 130~180단어).

## 꼭 지킬 것

- **지문·예문은 모두 새로 쓴다.** 실제 수능·모의고사·교과서·책의 문장이나 지문을 옮겨 오지 말 것(비슷한 주제·유형은 괜찮음).
- 영어는 자연스럽고 문법적으로 정확해야 한다. 정답이 하나뿐인지, 오답이 확실히 틀렸는지 두 번 확인.
- 해설은 왜 정답인지 + 대표 오답이 왜 틀렸는지를 짧게.
- 설명은 교과서 문체(…이다/…한다). 중1은 쉬운 말.
- 문자열 안 작은따옴표(')는 이스케이프(\')하거나 바깥을 큰따옴표/백틱으로. 영어 지문에 아포스트로피가 많으니 주의.
- 다른 전역 변수나 함수를 만들지 말고 `ENG.add(...)` 호출만 쓴다.

# 단어 학습 단원 (vocab-*.js)

학년마다 주제별 **단어 단원**을 만든다. 단어 카드(그림·🔊·뜻·예문)로 개념을 보여 주고, 문제는 앱이 단어 자료로 **자동으로 만든다**
(그림 보고 단어 고르기 · 영어로 고르기 · 예문 빈칸 · 듣고 뜻 고르기 · 영영 풀이). 유의어·반의어는 카드에만 보여 준다
  — 오답 보기는 같은 단원의 다른 단어이므로, 한 단원에 뜻이 거의 같은 단어 둘을 넣지 말 것.

```js
ENG.vocab('m1', '단어: 학교와 교실', {
  sub: '한 줄 설명',
  kw: ['school', 'classroom', '...'],
  words: [   // 정확히 24개
    { w: 'eraser', pos: 'n', ko: '지우개', em: '🧽', def: 'a small object used to remove pencil marks',
      ex: ['Can I borrow your eraser?', '네 지우개 좀 빌려도 될까?'], syn: '', ant: '' },
    ...
  ],
});
```

- `w` 단어(소문자, 구동사·숙어는 띄어쓰기 그대로) · `pos` 품사(n, v, adj, adv, prep, conj, phr) · `ko` 대표 뜻(짧게, 2개까지 쉼표).
- `em` **그림(이모지 1~2개)**: 단어의 뜻이 한눈에 떠오르는 것. 구체 명사·동작은 그대로(🍎 apple, 🏃 run),
  추상어는 뜻을 비유하는 그림(📈 increase, 🔍 analyze, ⚖️ fair, 🤝 cooperate, ⏳ temporary). **최대한 모든 단어에** 넣되,
  아무리 해도 뜻과 상관없는 그림만 떠오르면 빈 문자열('')로 둔다. 같은 단원에서 같은 그림을 두 단어에 쓰지 말 것(그림 문제 정답이 둘이 됨).
- `def` 쉬운 영영 풀이(학년 수준, 15단어 안팎). 단어 자체나 같은 어근을 풀이에 쓰지 말 것.
- `ex` [영어 예문, 우리말 뜻] — **예문에 그 단어가 원형 그대로(대소문자 무관) 정확히 한 번** 들어가야 한다(빈칸 문제가 된다). 새로 쓴 예문.
- `syn` 유의어 하나, `ant` 반의어 하나(있을 때만, 없으면 ''). 고등은 가능하면 채운다.
- 같은 학년 안에서 단어가 겹치지 않게. 학년 수준: 중1 기초 생활어 → 고3 수능 빈출 학술어.

검사: `node "E:/프로그램 제작/학습기/data/english/check.js" "<파일>"` (단어 수 24, 필수 칸, 예문 속 단어, 그림 중복, 단어 중복 검사)

# 듣기 단원 (content-listen.js)

`ENG.add`와 같은 형식(개념 3~4개 + 문제 15개)이고, 단원 제목은 `'듣기: …'`로 시작한다. 문제에 **`audio`** 를 넣으면
앱이 🔊 재생 버튼을 붙이고(기기의 영어 음성으로 읽음, M=남자 목소리 · W=여자 목소리), **대본은 답한 뒤 해설 아래에** 보여 준다.

```js
{ lv: 3, q: '대화를 듣고, 여자가 남자에게 부탁한 일로 가장 적절한 것을 고르시오.',
  audio: [['W', 'Tom, are you busy now?'], ['M', 'Not really. What is it?'], ['W', 'Could you water the plants while I am away?'], ['M', 'Sure, no problem.']],
  o: ['식물에 물 주기', '…', '…', '…'], a: 0, why: '여자가 집을 비운 동안 식물에 물을 줘 달라고 했다.' }
```

- 대본은 자연스러운 구어체, 새로 쓴 것. 화자는 'M' / 'W' (내레이션은 'M' 또는 'W' 한 명). 숫자·시간·가격은 읽기 쉽게(예: 'fifteen dollars', '3:30').
- 기계 음성이 읽으므로 약어·기호·이모지는 대본에 쓰지 말 것. 한 문제 대본: 중1 2~4줄, 고3 6~10줄.
- 모든 문제에 `audio`가 있어야 한다(개념 칸 `ex` 예문에도 🔊가 붙는다).
